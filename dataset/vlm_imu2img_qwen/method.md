# IMU2IMG转换器通过冻结Qwen的答案损失对齐

用户已同意两步实验：先检查旧图片上简化提示的作用，再保持Qwen所有参数冻结，只训练IMU→图像转换器。本方法属于**冻结VLM的有监督适配**，不称为整套零样本/零标签系统。

## 固定数据与图像

保留原16,461训练窗、4,727验证窗、3,708测试窗及犬只隔离划分。沿用IMU2IMG的两类三轴RMS、原200点窗口内部中心裁剪为196点、49个4点patch、224×224学习RGB图。R来自加速度，G来自陀螺仪，无磁力计的B通道保持中灰128。源方法与适配详见../vlm_imu2img/method.md。

新转换器从原ViT监督训练后、验证集选出的第7轮转换器初始化；不加载原ViT或原分类头进入对齐训练。原转换器和全部旧图保留。

## 训练目标

```text
IMU → 可训练转换器 → 可微8位RGB预处理 → 冻结Qwen视觉编码器/投影/语言模型 → 答案token
            ↑                                                  │
            └──────────────────真实JSON答案损失的梯度─────────────┘
```

只训练835,584个转换器参数，Qwen始终eval且requires_grad=False。冻结权重不等于禁用激活梯度：没有在Qwen前向外层包no_grad，答案损失能回传到输入像素及转换器。

仅监督最终JSON行为答案与EOS；图片、英文任务、非思考前缀、padding的标签全部屏蔽。简化英文文本只包含图像模态、patch时间顺序、任务、七类标签和JSON规则，不保留波峰/频率/轴基线等直接波形观察先验。提示在本轮新验证输出前固定。

## 与部署一致的可微像素路径

1. 转换器参数/优化器为FP32，转换器前向采用BF16，与旧图生成精度一致。
2. tanh输出映射到0–255并round至8位，训练用straight-through estimator保留梯度，前向值仍是8位像素。
3. 按当前官方Qwen处理器的融合归一化顺序计算`(byte-127.5)/127.5`；随后按16像素patch、2帧重复、2×2空间合并排列。
4. 得到每图196×1536的patch张量及`image_grid_thw=[1,14,14]`，对应49个合并视觉token。导出为224像素无损WebP，vLLM min_pixels=224²。

训练路径不经过PIL、WebP编码或detach截断。技术检查将同一8位RGB交给官方处理器，与可微路径比较：FP32误差低于1e-6、转BF16后逐位一致；转换器编码器/解码器及像素有非零梯度，Qwen没有梯度，完整Qwen参数内存SHA前后相同。首次检查发现融合归一化顺序差异，已在正式优化前修正，诊断日志保留。

## 固定训练与验证

3epoch，AdamW、LR1e-4、weight decay0.01、5%warmup后线性衰减、梯度裁剪1。双卡每卡microbatch16，有效batch32；DDP每epoch额外复制1个训练窗以平衡两rank。只优化转换器；不使用Qwen LoRA或新分类头。

每epoch记录完整验证集答案NLL，保存三个小型转换器checkpoint。训练结束后，分别导出三个checkpoint的全部验证图片，由同一个冻结Qwen/vLLM生成答案，按**完整验证集macro-F1最高**选模型；完全相同时选较早epoch。最后才导出所选checkpoint的测试图片并进行正式测试。

正式生成均用vLLM，温度0、关闭思考、最多32输出token、严格JSON解析，失败计错。训练使用Transformers支持像素梯度；vLLM用于生成式验证和测试。

## 对照与边界

第一步在旧图片的同一验证集上比较原提示与简化提示，再保留旧转换器＋简化提示的匹配测试基线。第二步与这个基线使用同一简化文本及相同Qwen、生成、图像处理设置；改变的是转换器对齐。原Qwen权重文件及训练前后的完整参数内存哈希都验证不变。

这是向指定Qwen模型学习图像表示的新适配实验，不是原IMU2IMG论文既有的VLM方案。图像人类可读性和跨VLM迁移能力需要另行评价；本任务覆盖原数据筛选出的整窗一致七种行为。当前测试集此前已被查看，本轮不据新测试输出调整提示或超参数。

## 本轮完成情况

三轮转换器的验证Macro-F1分别为0.080802、0.116907、0.128750，选中epoch3。`validation/epoch_1/`至`epoch_3/`分别保留4,727张验证图片；`images/`保存选中转换器生成的全部3,708张测试图片，`images.csv`记录来源窗口与文件SHA。图片使用匿名文件名，窗口、犬只与真值信息不会传入模型。

测试Macro-F1=0.125809、balanced accuracy=0.275129、accuracy=0.297465，全部解析成功。3,690/3,708个预测为Sitting或Walking，另17个Lying chest、1个Sniffing，其余三类没有被预测。因此本轮对齐提高了成绩，但七分类能力仍然较弱。[完整报告](../../results/qwen3.5_4B_imu2img_aligned_en/README.md)、[训练与校验](../../results/imu2img_qwen_alignment/README.md)、[转换器](../../models/IMU2IMG-Qwen3.5-4B-aligned/README.md)。
