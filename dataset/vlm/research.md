# 犬只 IMU 行为先验与本轮 VLM 协议

检索与冻结日期：2026-11-02。两份模型使用相同的 [prompt.txt](prompt.txt)，在测试推理前固定。该设置是“文献先验辅助的零样本分类”：没有训练样例图片、没有少样本示例、没有针对本任务微调。

## 文献依据与证据边界

1. [Kumpulainen 等，2021，原数据集行为分类论文](https://doi.org/10.1016/j.applanim.2021.105393)：提供七类行为定义；项圈上三种静态姿势难区分，项圈旋转会使姿态分布重叠；嗅闻定义为低头、口鼻近地，可伴缓慢移动。提示据此保留各类定义及静态类别歧义，不编造其唯一轴值。论文采用的窗口标签占比和重叠协议与本项目不同，本轮仍沿用本项目既有窗口。
2. [Gerencsér 等，2013，Identification of Behaviour in Freely Moving Dogs Using Inertial Sensors](https://pmc.ncbi.nlm.nih.gov/articles/PMC3820959/)：展示静态加速度中的重力偏置、运动时波动及陀螺仪信息，讨论固定方式和喘气干扰。传感器在背部，其解剖轴方向不能直接套用于本项目项圈。提示中的“稳定基线、小幅变化、旋转波动”是对基本信号机制的谨慎转述。
3. [den Uijl 等，2017，项圈加速度外部验证](https://doi.org/10.1371/journal.pone.0188481)：区分较慢行走、两拍对称小跑和不对称的 canter/gallop；其静态类别合并了多个姿势。提示使用步态节律定义，没有照搬该研究的准确率或分类器。
4. [Bolton 等，2021，项圈加速度与速度/步态](https://doi.org/10.3390/ani11051262)：该实验的汇总加速度可区分行走与更快步态，但较快步态之间仍难分；个体体型和运动方式影响信号。提示不将幅值、频率或速度写成通用阈值。
5. [Hayati 等，2019，Analysis of Agile Canine Gait Characteristics Using Accelerometry](https://doi.org/10.3390/s19204379)：灰狗背部传感器记录的疾跑具有可分析的周期与冲击峰，步态和步幅对应的频率分量可见。由于犬种、位置与条件不同，本轮不把其频率或峰值移植到项圈阈值。

## 哪些内容是推断

文献提供行为定义和一般信号机制，并未给出当前六个原始通道上、适用于所有犬只的七类波形模板。把步态节律映射为“重复振荡”、把颈部搜索动作映射为“可能的基线变化和不规则角运动”，属于本轮的定性机理推断，已经在提示中用“可能”“通常”表达。三种静态行为使用相近的运动线索，保留其固有歧义。

未编造 `x/y/z` 的解剖方向、`g`/`°/s` 单位、某姿势固定重力值或某动作的固定 Hz 范围。提示没有使用测试犬的统计量、逐类测试特征或已知预测成绩。

## 固定输入与绘图

- 严格复用 `../splits/windows.csv` 与 `../splits/dog_splits.json`。训练范围拟合用 16,461 个训练窗口，正式推理用全部 3,708 个测试窗口；不另切窗或挑选样本。
- 保留 200 点和全部六个通道，直接绘制原始存储值，不转为模长，不对单图归一化。
- 每通道的显示范围使用训练样本的 0.1% 和 99.9% 分位数，再向两侧各扩展分位跨度的 5%。该稳健范围在测试推理前确定；极端点会被显示边界截断，以三角标记并在 `images.csv` 中记录每通道上下界外点数和原始最小/最大值。此信息损失会纳入结果说明。
- 六个纵向子图，通道顺序固定；1280 × 1152 像素、DejaVu Sans、字号 11 pt、线宽 1.2 pt、白底、固定颜色，统一无损 WebP，无嵌入元数据。
- 横轴始终为窗口内 0–2 秒。导出尺寸为两份本地模型 32 像素空间合并步长的整数倍；使用实际 processor 检查空间尺寸及重建像素，检查记录见 `processor_check.json`，实际处理后预览见 `processor_preview_4b.webp`、`processor_preview_27b.webp`。
- `preview.webp` 来自固定清单中的首个训练窗口，仅用于检查图形和运行入口，不计入正式测试。正式图片使用不含标签、犬只 ID 或 Task 的不透明哈希文件名。
- 推理只向模型传入无元数据的 RGB 像素和固定 prompt；关联窗口、真值、犬只和集合信息保存在外部清单中，不作为模型输入。

## 推理与评价约定

使用已下载的两份官方 BF16 权重，保留视觉编码器，Transformers 离线推理。两份模型都关闭思考模式，贪心生成，最大输出 32 token；每窗口独立一轮对话，无历史上下文。输出要求为一个七类标签 JSON。

输出解析在推理前固定：允许去除完整 Markdown 围栏；JSON 必须只有 `label` 字段，标签允许大小写归一到七个固定英文名称。拒绝、空输出、超长截断或不合规范的输出都记录为失败，不根据真实标签重试或改提示。失败在总体指标中按错误计算，另报告解析成功率。显存不足仅调整批处理大小，不改变图片、提示或样本范围，并记录事件。

记录原始回答、解析状态、输入/输出 token 数、批处理预处理和 GPU 生成耗时、模型载入耗时、显存峰值、渲染时间及处理范围外点数。批处理的“每窗耗时”是批次总时间除以批量的摊销值，不能直接当作单请求延迟；单独保存训练窗口技术预检耗时。端到端实测墙钟时间与组件时间分开报告，均不含传感器采集的 2 秒等待。

最终报告 Accuracy、固定七类 Macro-F1、Balanced accuracy、每类指标、每犬指标、含失败列的混淆矩阵，以及测试犬整体 bootstrap 区间。保持已有 CNN、随机森林文件不变。正式测试输出一旦开始，不再根据测试成绩修改提示或绘图协议。
