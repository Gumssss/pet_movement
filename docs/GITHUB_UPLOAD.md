# GitHub 仓库与本地复现

该仓库对应 `Gumssss/pet_movement`。代码、文档和无密钥的配置模板留在仓库，`data/`、`models/` 与 `outputs/` 是 Git 忽略的本地软链接。[项目入口](../README.md)

克隆后按项目入口恢复上述目录。运行训练前，在 macOS 的 `collar` 环境安装 `scripts/requirements_inrtlwrist.txt`。InrtlWrist 的固定版本可由 `scripts/download_inrtlwrist.py` 下载。固定犬只划分和实验输出随本地研究工作区管理，复现时沿用对应协议。

原始传感器文件、批量图像、训练权重和本地凭证由各自的本地目录管理。上传前按研究数据的共享要求核对需要另行分发的文件。[本地输出索引](../outputs/README.md) · [归档清单](../outputs/records/cleanup_manifest.json)

第三方代码保留各自的许可证和声明。
