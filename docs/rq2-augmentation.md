# RQ2 · 哪些项圈 IMU 数据增强有助于识别新犬的行为？

## 当前状态

本轮沿用 RQ1 确定的时域 CNN 训练配方，恒定学习率 3e-4。继续比较八种单项增强，以及按验证成绩选出的强度和组合。早期恒定学习率 0.002 的重跑完成 10 次训练后停止，原目录为 `outputs/RQ2/cnn_augmentation_v2/`，已归档。[RQ1 搜索结果](../outputs/RQ1/lr_search_seed0/README.md)

## 实验设计

主问题是增强能否提高原始测试窗上的七类 macro-F1。分别观察两种可能相反的效应：模型能否更好地适应不同犬只、佩戴方式和步速，以及增强是否抹掉了坐、站、卧之间本来就细微的区别。以下是实验设计，所有强度都是待验证的候选值。

## 第一轮 · 单项比较

用同一个时域 CNN 跑原窗对照和下表八个条件。前五项模拟可能出现在记录中的变化，均可进入最终候选。后三项也实际安排训练，用来研究模型依赖哪些信号，仅报告验证表现。每个条件配对三个种子，共 27 次 CNN 训练。

| 条件 | 每次怎样改变一个 2 秒训练窗 | 重点看什么 |
|---|---|---|
| 同标签重切窗 | 在同犬、同场次、时间戳连续且逐点同标签的记录中，均匀抽取一个可用的非零偏移，最多前后 20 点（0.2 秒），取满 200 点。无合法偏移时用原窗 | 边界变化能否帮助识别同一动作，逐类报告可用邻窗与实际重切比例 |
| 小角度旋转 | 均匀取三维单位轴，角度均匀取 0–10°。加速度和角速度的三轴向量在整窗共用同一个旋转矩阵 | 模拟项圈小幅偏转，尤其关注 Sitting 与 Standing 的双向误判 |
| 动态幅值缩放 | 加速度、角速度分别抽取 0.9–1.1 的系数，各组三轴共用，对各轴相对窗口均值的波动缩放，再加回均值 | 幅度差异能否被容忍，静态姿态线索是否保留 |
| 微弱加性噪声 | 对每轴、每点独立加零均值高斯噪声。标准差先取该轴原始训练集标准差的 1%，用原始存储单位实现 | 小幅读数扰动是否有益，尤其观察低活动量的坐、卧；该比例是实验强度，传感器噪声底尚未实测 |
| 步态速度扰动 | 仅对 Walking、Trotting、Galloping，六轴共用以窗中心为原点的线性时间变换，速率均匀取 0.95–1.05，从连续同标签段插值回 200 点。加速需要窗外上下文，缺失时保留原窗 | 步频变化是否改善跨犬识别，逐类记录实际应用率及快慢方向，核查步行与小跑是否更易混淆 |
| 窄频带遮挡 | 对原窗做实数 FFT，在 0.5–50 Hz 随机抑制两个相邻的非零频点，再逆变换回 200 点。六轴共用频带，保留直流分量 | 模型是否过度依赖局部频带；输入和基线仍是相同的时域 CNN |
| 大幅朝向变化 | 随机取一个传感器轴，绕它旋转 180°，等价于其余两轴同时翻转。两组三轴使用同一旋转 | 与 10° 旋转对读，估计强制模型忽略大幅朝向变化对姿态识别的代价 |
| 时间段乱序 | 以 0.5 秒为单位把窗分成四段，均匀抽取一种非原序排列，六轴使用相同顺序 | 比较步态与姿态对段落顺序的依赖；拼接处也会引入突变，不能单独归因于时序 |

原清单中 16,461 个训练窗有 15,876 个在前后 2 秒找到同犬、同场次、同标签的候选邻窗，疾跑仅 23/99。实施时再核对逐点连续性。各组沿用原训练窗的采样频率，不为提高覆盖率而重复采样疾跑。先用训练犬抽查各类原窗与增强窗，核验旋转前后的三轴模长、缩放前后的均值、重切边界与步态主频变化，并保存失败及跳过次数。

## 第二轮 · 强度与组合

1. 按三个种子的原样验证 macro-F1 均值，在前五项中选前两项。每项各补一档较弱和较强的设置。重切上限取 0.1 / 0.3 秒，旋转上限取 5° / 20°，缩放半宽取 5% / 15%，噪声比例取 0.5% / 2%，速度半宽取 2.5% / 7.5%。应用概率始终为 50%。四个新增配置共 12 次训练。
2. 两项各自取验证均值最高的强度，再跑两个三种子组合。**随机择一**在触发增强的窗上等概率选其中一项。**同时施加**在触发窗上依次施加两项，固定顺序为重切、变速、旋转、缩放、加噪。两组均保留 50% 原窗，遇到不适用的操作时跳过该项。比较组合与最好单项，并记录每窗实际变换数。此步共 6 次训练。
3. 两轮共 45 次 CNN 训练。最终在原窗基线、五个物理动机单项及其强度和组合中，按验证三种子平均 macro-F1 选一个配置。并列取操作数少者，再取扰动较弱者，仍同分按表序。基线胜出也作为结果。三个诊断条件单列，避免用当前项圈尚未证实会出现的大扰动选择最终配方。

## 公平对照与结果解读

- 沿用 RQ1 的犬只划分（27/9/9）、六轴、100 Hz、200 点、七类纯行为窗。使用 collar 环境、PyTorch MPS、FP32 和同一时域 CNN。每个种子配对初始化和训练窗顺序，另设增强随机数流。沿用 batch 128、AdamW、恒定学习率 3e-4、权重衰减 0.0001、dropout 0.2、训练类频率平方根倒数加权，以及 20261101–20261103 三个种子。本轮最多 200 个 epoch，每轮结束在原样验证犬上计算 macro-F1。相对历史最佳得分的改善超过 0.000001 时保存权重，连续 10 轮未改善即停止。测试使用验证最佳轮次。
- 每个原训练窗每轮出现一次，在线以 50% 概率尝试增强，再用原始训练犬拟合的逐通道均值和标准差归一化。所有组每轮的更新数相同，各自按原样验证 macro-F1 保存最佳轮次。验证及测试均使用原窗。
- 主结果为锁定方案与匹配基线在同一批测试犬上的 macro-F1 差值（三种子各自计算后平均）。以犬为单位配对重抽样 2,000 次，报告差值和 95% 区间。若基线入选，报告验证最高的增强作预定次要比较。固定测试犬已用于早期模型对照，本轮结果限于这一划分。
- 次要结果包括每类 F1 和支持数、坐姿召回、坐站卧的双向混淆数、步态三类之间的误判，以及各犬的变化。保留三组种子的单独结果。验证疾跑只有 12 窗，同时报告正确窗数和犬数，避免让一两个窗的变化主导解释。
- CNN 筛选共 45 次训练。将按验证成绩选出的增强配方迁移到全量微调 InrtlWrist，使用 RQ1 选出的恒定学习率 3e-5、FP32、相同三个种子、相同早停规则。增强在 100 Hz 原始训练窗上应用，再用抗混叠滤波降采样至 50 Hz，取中心 96 点。用 RQ1 同配方的无增强微调作对照。

单项设计参考了可穿戴 IMU 的增强实验和跨数据集的时序增强对照；上面的强度、类别限制和排序规则是本项目的实验选择。[Um 等](https://arxiv.org/abs/1706.00527) · [Iwana 与 Uchida](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0254841) · [频域 CNN 训练设置](../outputs/RQ3/README.md)

## 运行和核验

在项目根目录用 `collar` 环境运行。训练命令接收新的输出目录，先写入验证集选择结果，再评价测试犬。报告命令从保存的逐窗预测独立重算各配置验证分数、逐犬混淆矩阵和测试差值区间。

```sh
conda run --no-capture-output -n collar python scripts/train_cnn_augmentation.py --device mps --max-epochs 200 --patience 10 --lr 3e-4 --output outputs/RQ2/cnn_augmentation_repeat
conda run -n collar python scripts/report_cnn_augmentation.py outputs/RQ2/cnn_augmentation_repeat
conda run --no-capture-output -n collar python scripts/train_inrtlwrist_augmentation.py --device mps --cnn-run outputs/RQ2/cnn_augmentation_repeat --output outputs/RQ2/inrtlwrist_augmentation_repeat
```

## 首轮结论（旧设置，最多 35 轮、早停耐心 7）

45 次 CNN 训练已完成。验证集选出的 ±15% 动态幅值缩放在 9 只测试犬上得到 0.7639 的平均 macro-F1，配对基线为 0.7719。差值为 −0.80 个百分点，犬级 95% 区间为 [−2.50, +1.28]。本轮保留原窗 CNN 作为基线。[首轮报告的归档位置](../outputs/records/cleanup_manifest.json)
